## Verified OK (recent changes)

- **Save always enabled + highlight:** Customers, Suppliers, Branches, Users, Roles, PO wizard Next, Sales Orders Save/Next. Empty required fields turn red (`rgb(211,47,47)`, 1.6px), toast appears, first field scrolled into view. Branches/Users/Roles/Customers/Suppliers list exactly the expected required labels.
- **Customers:** Company vs Individual forms (no Company Name/Occupation on Individual; no Contact Person field on Company; Contact Person tab only for Company); Title blank by default; Contact No 1 required for both; duplicate numbers blocked with helper text; Currency in General defaulting to LKR; create from General only (single POST on `dblclick`); Address tab (line 1, city, country required) and Payment tab (account name, bank name, account no required) save independently with one PUT each and lock afterwards; table has Payment Terms and no Company column; contact-person Title/Contact No required (Add disabled until valid).
- **Suppliers:** Country required in General, Lead Time units Days/Weeks only, lead time saved (3 days), General-only create (single POST), Payment tab unlocks, contact-person panel requires Title and Contact No with blank Title/Gender, single POST.
- **Branches:** one required "Location" field; create (one POST each for branch and location), edit location (PUT branch + PUT location).
- **Users:** section order Account → Personal → Access & Permissions → Profile Picture; picture draft on create uploads after creation (POST /users + POST profile-picture, picture served), Browse disabled in view mode.
- **Sidebar:** Warehouse group contains Good Received Notes, Supplier Voucher Payment, Purchase Returns and an Approvals group (ITN Approvals, Purchase Return Approvals); menu entries are real links (open in new tab).
- **Approvals pages:** no selection checkbox column or bulk buttons (PO, Quotation, Purchase Return).
- **PO wizard:** In-Transit Qty column, required highlight on Next, MOQ warning before Review and again before create ("Continue Anyway"/"Go Back"), expected delivery date pre-filled (Sunday 11 Oct + 3 working days = Wed 14 Oct) with the "Recalculated when approved" note, single batch POST.
- **PO rejection:** rejecting with a reason shows a red "Rejected — Reason: …" banner on the PO page; PO detail Total row is aligned under Amount; no quotation link in the PO detail.
- **Smoke:** all 22 in-scope routes load with no console errors and no failed API calls.
- **XSS:** records with `<img src=x onerror=alert(1)>` names (created by the API tester) render escaped in the Users list; no dialog fired.
