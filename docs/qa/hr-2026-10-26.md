## Passed
- All 14 HR routes load: 0 console errors, 0 failed API calls, no spinners stuck. Mobile 390px: no horizontal overflow on 6 sampled pages.
- No token -> 401 on 26 HR GETs. No password/token/hash fields in the list responses.
- Strict validation (clean 422/400/404, never 500): negative/zero/NaN/Infinity/1e12 amounts, 10k-char text, int4 overflow, impossible dates (2026-02-30), future/ancient dates, to_date < from_date, negative/over-366 leave, check-out <= check-in, bad time `25:99`, negative/huge minutes, unknown employee/branch/asset/leave type, duplicate attendance day, negative leave-type values, invalid enums.
- Mass assignment: extra `id`, `is_superuser`, `created_by` on department create were ignored.
- XSS: `<img src=x onerror=alert(1)>` in department name and deduction reason renders as text, 0 dialogs.
