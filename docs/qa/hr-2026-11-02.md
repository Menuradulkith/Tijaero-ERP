### What worked (OK)
- **All 20 HR pages** load with no console errors, failed API calls, blank screens or stuck spinners; no horizontal overflow at 390 px (Loans, Salary Profiles, Payroll Processing, HR Setup → Payroll); loan dialog fits a phone screen.
- **Salary profile**: allowance editor, live totals (133,500 total / 123,500 EPF earnings / 9,880 EPF), Save disabled while empty, double-click Save = 1 POST; increment dated next month adds a history row (+10,000, 7.49%) and payroll still pays the old salary this month.
- **Payroll run** matches a hand calculation to the cent: basic 120,000 + BRA 3,500 + Transport 10,000 + OT 3 h 2,315.62 = gross 135,815.62; EPF 9,880 / 14,820, ETF 3,705; APIT 0 (taxable 125,815.62 under the relief); stamp 25; loans 12,000; net 113,910.62.
- **Payslip** opens from the row print button and lists every earning, deduction and employer contribution, amount in words; names render escaped (XSS attempt shown as text).
- **EPF Form C, ETF R4, APIT schedule, bank file** download with the right file names and totals; missing EPF numbers / bank accounts are reported as warnings.
- **Leave**: lieu day granted once, duplicate and working-day grants refused; lieu leave applied → approved → cancelled, balance returns (used 1→0).
- **Separation** → final settlement (no gratuity under 5 years; loans owed listed) → reinstate.
- **Cancelling a payroll batch** gives loan instalments back (balance 30,000 again).
- **Security**: all 16 new endpoints return 401 without a token and 403 for `qa-none`; 14 loan validation cases, 7 payroll-settings cases, 7 allowance cases and 5 lieu cases rejected with 4xx (no 500); mass assignment (`status`, `loan_no`, `recovered`, `is_superuser`) ignored; malformed JSON → clean 422; returns send `Cache-Control: no-store` and `nosniff`.
- **Races**: 8 parallel full repayments → 1×200 + 7×400, loan settled once; 5 parallel cancels → 1×200 + 4×400; 6 parallel lieu grants for a granted day → 6×400.
